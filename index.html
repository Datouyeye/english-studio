English Studio

这是一个完全运行在你浏览器里的英语学习工具：题库、翻译历史、学习库都存在本浏览器的本地存储中，AI 出题与判定直接调用你配置的 API（支持任意 OpenAI 兼容服务）。所有数据只保存在本浏览器，不会上传。

① 配置 API（第一步，必做）

先去 填一个 API Key（支持任意 OpenAI 兼容服务，默认 DeepSeek）。Key 只保存在本浏览器，不会上传到任何服务器；若把这个网页分享给别人，对方也能使用此 Key，请自行承担费用风险。

② 翻译练习：刷题 + 判分

看中文 → 在输入框写英文 → 点「提交判定」。AI 会给总评、更地道的改法和参考答案；完成度不够就按建议再改一版，直到满意。答得好的表达可以点「收藏该表达」，会存进学习库。题库每天自动新增 10 条，也可以点「增加题目」自己补充。

③ 文章阅读：AI 分级改写

粘贴或上传一段中文/英文材料（支持 txt 文件），选目标水平（A2/B1/B2），AI 会翻译并改写成适合你水平的英文。阅读时选中文本，可一键加入学习库。

④ 学习库：收藏表达 + 阅读收藏 + 翻译历史

「收藏表达」存练习中收藏的词汇；「阅读收藏」按文章整理成合集，阅读时收藏的词句都在这里；「翻译历史」存你提交过的翻译（最后版本答案）。

⑤ 卡片复习：巩固记忆

把学习库里收藏的表达做成卡片，正面英文、翻面看释义，按「从新到旧」或「随机」顺序复习。
