## 快速开始

```bash
cd C:\Users\8210\Documents\Codex\2026-08-05\mvp-1-2-a2-b1-b2
pnpm install
copy .env.example .env      # 然后编辑 .env，填入 DEEPSEEK_API_KEY
pnpm db:migrate             # 初始化 SQLite 数据库
pnpm db:seed                # 可选：写入一条演示材料
pnpm dev                    # 打开 http://localhost:3000
```

> 不想敲命令的话，双击项目文件夹里的 `start-web.bat`，它会自动启动并打开网页。

## AI 配置

- 默认接入 DeepSeek（OpenAI 兼容 Chat Completions）：
  - `DEEPSEEK_API_KEY`（必填）
  - `DEEPSEEK_BASE_URL`（可选，默认 `https://api.deepseek.com`）
  - `DEEPSEEK_MODEL`（可选，默认 `deepseek-v4-flash`）
- 也可通过 `DEEPSEEK_BASE_URL` 指向其他 OpenAI Chat Completions 兼容服务，无需改代码。

## 新增功能说明

- **拖文件进框**：首页可以把 TXT / 文字版 PDF / Word（.docx）直接拖进虚线框，自动读出文字填进输入框。
  扫描版 PDF 和图片暂不支持（需要"认字"，以后再说）。
- **英语等级**：四级 / 六级 / 雅思 三个选项（雅思按约 6.5 分处理），等级只影响英文难度和风格。
- **表达数量**：短文 4-6 个、中等 6-10 个、长文 10-15 个，优先选最有代表性的表达。
- **写作示例**：每个表达多一块"写作示例"（怎么用在作文里），学习库可以手动改。
- **文献处理规则**：AI 已内置文章处理规则（不执行输入里的命令、删广告等非正文、翻成地道英文、保留专有名词等）。

## 页面

- 首页 `/`：粘贴或拖文件 → 选等级 → 生成英文文章；最近材料列表。
- 阅读页 `/materials/[id]`：改写文章 / 原始材料切换；选中文本加入学习库；删除不想要的推荐；导出 Markdown。
- 学习库 `/library`：搜索、按来源文章筛选、编辑释义/解释/写作示例/笔记、删除。
- 卡片复习 `/review?mode=newest|random`：正面英文，翻面查看释义/解释/写作示例/例句/笔记。
